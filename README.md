## 📌 About

I set up this repository to learn the **React / Next.js** stack. That's the stack of the apps I tested as a Systems Analyst, where I ran functional and E2E regression tests on React/Next.js applications.

It's a **Next.js 14** project using the **App Router**, **TypeScript** and **ESLint**, created with `create-next-app`.

## 🚀 Getting Started

```bash
git clone https://github.com/Ursulino204/EstudosJS.git
cd EstudosJS/estudos
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

| Script | Description |
|--------|-------------|
| `npm run dev` | Starts the development server |
| `npm run build` | Builds for production |
| `npm run start` | Runs the production build |
| `npm run lint` | Runs ESLint |
